🎹 ToneForge+ Feature Showcase

Overview

ToneForge+ is an advanced web-based music composition workstation featuring three powerful composition modes, an expanded instrument library, custom instrument creation, and professional keyboard shortcuts.

🎼 Three Composition Modes

ENHANCED

1. Visual Sequencer

Traditional grid-based pattern sequencer with 16-step patterns.

  • Multiple tracks with different instruments
  • Click to activate/deactivate notes
  • Real-time playback
  • Visual feedback for active notes
NEW

2. Score Editor

Traditional music notation with visual staff representation.

  • Visual Staff: See your notes on a treble clef staff
  • Note Input: Click to add notes with specific pitch and duration
  • Musical Parameters:
    • Tempo: 40-240 BPM
    • Time Signature: 4/4, 3/4, 6/8, 2/4
    • Key Signature: C Major, G Major, D Major, F Major, A Minor
  • Duration Options: Whole, Half, Quarter, Eighth, Sixteenth notes
  • Playback: Hear your composed score with any instrument
ENHANCED

3. Live Coding

Code-based pattern creation with real-time feedback.

  • Simple syntax for musical patterns
  • Real-time pattern parsing
  • Visual waveform feedback
  • Pattern library with examples

Example:

bpm:120
instr:violin
melody: [C4-4n, E4-4n, G4-4n, C5-4n]
rep(melody, 4)

⌨️ Keyboard Shortcuts

NEW

Professional Keyboard Shortcuts

Work faster with Command/Control-based shortcuts that don't interfere with browser shortcuts.

Space Play/Pause in current tab
Cmd/Ctrl + N Create new score
Cmd/Ctrl + S Save composition
Cmd/Ctrl + P Play/Pause
Cmd/Ctrl + Z Undo last action
Ctrl + Enter Play pattern (Live Coding)

🎨 Custom Instrument Maker

NEW

Create Your Own Instruments

Revolutionary feature that lets you create custom instruments from audio samples!

How It Works:

  1. Upload or Record: Import an audio file or record directly from your microphone
  2. Specify Base Note: Tell the app which note your sample represents (e.g., C4, A3)
  3. Automatic Pitch Shifting: The app calculates and generates all other notes automatically
  4. Preview & Tune: Test your instrument with pitch adjustment (-12 to +12 semitones)
  5. Save & Use: Your custom instrument is saved and ready to use in compositions

Features:

  • Support for various audio formats
  • Real-time microphone recording
  • Pitch-shifting algorithm for note generation
  • Preview with adjustable pitch
  • Persistent storage in browser (localStorage)
  • Use in any composition mode
