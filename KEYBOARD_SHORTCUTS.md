# Keyboard Shortcuts

ToneForge+ now supports keyboard shortcuts for faster workflow!

## Global Shortcuts

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Space` | Play/Pause | Toggle playback in current tab (Composition or Live Coding) |
| `Cmd/Ctrl + N` | New Score | Create a new empty composition |
| `Cmd/Ctrl + S` | Save | Export current composition data |
| `Cmd/Ctrl + P` | Play/Pause | Toggle playback (alternative to Space) |
| `Cmd/Ctrl + Z` | Undo | Revert to previous arrangement |

## Notes

- `Cmd` key is for macOS
- `Ctrl` key is for Windows/Linux
- Shortcuts are designed not to interfere with browser shortcuts
- Space bar is disabled when typing in input fields or text areas
- Ctrl+Enter in Live Coding editor triggers pattern playback

## Usage Tips

1. Use `Cmd/Ctrl + N` to quickly start a new composition
2. Save your work frequently with `Cmd/Ctrl + S`
3. Use Space for quick play/pause during composition
4. Keyboard shortcuts work across all tabs (Composition, Score Editor, Live Coding)
